Firefly Cove uses the Presage SmartSpectra SDK to measure your pulse and breathing rate from a camera, no wearables, no contact. The garden's fireflies glow with your heartbeat and its mist breathes with you. It is a relaxation toy, not a medical device: it makes no diagnosis and should never be used for medical decisions.

  • Camera: the camera starts only when you press Begin, and only on this computer. You can stop it at any moment.
  • Processing: the SDK analyses video on this device. Your video is never recorded, saved, or uploaded by this app.
  • Data: measurements live only in this page's memory and are forgotten when you stop or close the tab. Nothing is stored, shared, or sent to any analytics or AI service.
  • SDK telemetry: this app switches the SmartSpectra SDK's optional aggregate telemetry off. The SDK does contact Presage's servers to validate the developer API key, that is the only network call it makes on your behalf.

⚙️ Setup needed: no SmartSpectra API key is configured on the server yet. Register for a free key at physiology.presagetech.com, put it in .env as SMARTSPECTRA_API_KEY, and restart the server.
